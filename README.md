# Online Book Store — PHP

A PHP/MySQL web project for practicing the fundamentals of an online bookstore workflow.

## Source
The application is under `online-book-store-project-in-php-master/`.

## Local setup
1. Install PHP and MySQL.
2. Configure the database connection used by the application.
3. Place the project in a local PHP web-server document root.
4. Start Apache and MySQL.
5. Open the application's entry page in a browser.

Database credentials and setup depend on the original project environment, so review its configuration before running it.
